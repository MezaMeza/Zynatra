ZYNATRA

Arquitectura de Software y Modelado de Base de Datos

Este documento contiene el diseño de arquitectura y modelado de datos para la plataforma Zynatra. Incluye el modelo Entidad-Relación normalizado hasta la Tercera Forma Normal (3FN), asegurando la integridad referencial y eliminando redundancias, además de los tres diagramas UML fundamentales que describen el comportamiento, la estructura y las interacciones del sistema.

1. Modelo Entidad-Relación (Normalizado 3FN)

La base de datos (diseñada para Firestore/NoSQL pero modelada lógicamente de forma relacional) separa la información de los usuarios de su progreso académico y sus transacciones, garantizando la Tercera Forma Normal.
