ZYNATRA

Documentación de Interfaz y Desarrollo (UI/UX)

Este documento certifica el cumplimiento de los requerimientos de Interfaz y Desarrollo del sistema Zynatra, detallando la implementación de interfaces navegables dinámicas, el sistema estricto de validación de formularios y la estructura visual completamente responsiva y adaptativa para dispositivos móviles Android.

1. Estructura Visual Responsiva (Mobile-First)

El sistema fue diseñado con una arquitectura "Mobile-First" utilizando CSS moderno puro, garantizando que los elementos se acomoden perfectamente sin distorsionarse en cualquier tamaño de pantalla, desde monitores de escritorio hasta dispositivos móviles compactos.

Puntos de Quiebre (Breakpoints)

  • > 768px (Desktop): Layout de doble panel (Sidebar izquierdo de 250px + Contenido Principal).
  • ≤ 768px (Tablet/Móvil): El sidebar colapsa y se transforma en una barra de navegación inferior (Bottom Tab Bar) anclada a la pantalla.
  • ≤ 420px (Android): Reducción paramétrica de paddings y fuentes.

Tipografía Fluida

Implementación de la función matemática clamp() en CSS para escalar tipografías dinámicamente sin usar múltiples media queries, asegurando legibilidad sin desbordamientos:

font-size: clamp(1rem, 2vw, 1.25rem);

Optimizaciones Específicas para Android (Capacitor)

Para garantizar una experiencia de App Nativa al compilar con Capacitor, se implementaron las siguientes reglas:

  • Prevención de Zoom: Se configuraron todos los inputs con font-size: 16px para evitar que Chrome/Android haga zoom automático al enfocar un campo.
  • Safe Area Insets: Uso de padding-bottom: env(safe-area-inset-bottom) en la barra de navegación para evitar superposiciones con la barra de gestos de navegación de Android.
  • Toque Fantasma: Desactivación del destello azul en botones usando -webkit-tap-highlight-color: transparent y prevención de doble toque táctil con touch-action: manipulation.

2. Arquitectura de Interfaces Navegables

Zynatra está construida como una Single Page Application (SPA) en React. En lugar de recargar la página entera o depender de enrutadores complejos, utiliza un sistema de navegación por estados (React State) que inyecta componentes dinámicamente, garantizando transiciones instantáneas.

Controlador Mecanismo de Navegación Comportamiento UX
App.jsx Renderizado condicional basado en el rol (Student, Teacher, Admin). Protege las rutas. Un estudiante nunca puede acceder a vistas de docente mediante manipulación de URLs.
Sidebar.jsx Actualización del estado global de la vista activa (activeTab). Resalta visualmente el ícono y texto de la pestaña actual. En móvil, mantiene la navegación al alcance del pulgar.
Paginación Interna Manejo de pasos (steps) en memoria. En flujos como el Test Vocacional, se navega entre preguntas sin cambiar de "página", usando barras de progreso suaves.

3. Validación de Formularios Funcionales y Seguros

El sistema cuenta con validaciones estrictas tanto en tiempo real (Client-side) como en procesamiento lógico para evitar la inyección de datos corruptos, proteger la integridad de la base de datos y guiar al usuario ante errores tipográficos.

Módulo de Autenticación y Registro

  • Sanitización de Entradas: Todo correo electrónico ingresado es procesado automáticamente por .toLowerCase().trim() antes de validarse.
  • Feedback en Tiempo Real: Alertas visuales inmediatas si hay campos vacíos, si las contraseñas no coinciden o si el formato del correo es inválido.
  • Manejo de Estado: Bloqueo de botones repetidos (estado loading = true) para evitar múltiples envíos del formulario al servidor por error del usuario o lag.

Sistema de Recuperación de Cuenta (3 Pasos)

  • Cajas OTP (One Time Password): Interface de 6 inputs individuales para el código de seguridad. Soporta pegado de portapapeles y auto-avance al siguiente campo tras teclear.
  • Seguridad de Intentos: Bloqueo temporal del formulario tras 5 intentos fallidos de ingresar el código.
  • Medidor de Fuerza: Validación de la nueva contraseña requiriendo al menos 6 caracteres y mostrando un semáforo visual de seguridad (Rojo/Amarillo/Verde).
